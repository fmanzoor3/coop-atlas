Set up your shared library

Use this page for initial Supabase setup. If you have already run both queries, open the app and pair your device. Your local saves stay separate until you choose to transfer them.

1. Create the database tables

Copy the setup SQL below. Open your project in Supabase, choose SQL Editor → New query, paste it, then tap Run. Run this script once. It creates empty tables and access rules, without importing game data.

View SQL

2. Enable anonymous sign-in

In Supabase, open Authentication → Sign In / Providers. Find Anonymous Sign-ins, enable it, then save. This lets a device connect without an email address. It cannot access your data until paired.

3. Generate private pairing codes

Copy this second SQL query. Paste it into a new SQL Editor query and run it. The Results panel will show four codes. Save them privately; each pairs one browser/app installation and expires after seven days.

View SQL

Do not put the generated codes in GitHub or this chat. You can run this query again later to make fresh codes.

4. Pair your device

Open Coop Database, choose Fred or Manu, paste one private pairing code, and tap Connect shared library. Use another code on the other device. You can switch profiles later with the profile button. If something fails, share the error text with private codes hidden.

No email login is needed. Each paired device will remember its access and can switch between Fred and Manu in Settings. Safari and a Home Screen app may need separate pairing. Before the first data transfer, export existing game saves from both.
